# Favicon Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a small browser icon for the Rodri y Lu wedding invitation.

**Architecture:** Use a static SVG favicon committed with the site assets. Reference the same icon from both the invitation and the typography test page with a cache-busting query string so browsers refresh cached favicon state.

**Tech Stack:** Static HTML, SVG, Node test runner.

## Global Constraints

- Keep the site static and compatible with GitHub Pages.
- Use the chosen typography direction: Quicksand + Cormorant Garamond.
- Keep copy informal and intimate.
- Do not add external favicon generation dependencies.

### Task 1: Add Favicon Asset And References

**Files:**
- Create: `favicon.svg`
- Modify: `index.html`
- Modify: `fuentes.html`
- Modify: `tests/links.test.mjs`

**Interfaces:**
- Consumes: Existing static pages served from repository root.
- Produces: `favicon.svg` referenced by `<link rel="icon" type="image/svg+xml" href="favicon.svg?v=2">`.

- [ ] **Step 1: Write the failing test**

Add a Node test that reads `index.html`, `fuentes.html`, and `favicon.svg`.

```js
test('pages expose the wedding favicon', async () => {
  const indexHtml = await readFile(new URL('../index.html', import.meta.url), 'utf8');
  const fontsHtml = await readFile(new URL('../fuentes.html', import.meta.url), 'utf8');
  const favicon = await readFile(new URL('../favicon.svg', import.meta.url), 'utf8');

  const faviconLink = /<link rel="icon" type="image\/svg\+xml" href="favicon\.svg\?v=2">/;

  assert.match(indexHtml, faviconLink);
  assert.match(fontsHtml, faviconLink);
  assert.match(favicon, /<svg[^>]*viewBox="0 0 64 64"/);
  assert.match(favicon, />R\+L</);
});
```

- [ ] **Step 2: Run test to verify it fails**

Run: `node --test tests/links.test.mjs`

Expected: FAIL because `favicon.svg` does not exist and the pages do not reference it.
